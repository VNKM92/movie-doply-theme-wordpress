== Description ==
DoodhTheme is a production-grade, ultra-responsive, and SEO-optimized WordPress Theme built from the ground up for movie, TV series, seasons, and episodes streaming platforms (following DooPlay & DBMovies architecture).

== Features ==
* Movies & TV Shows Custom Post Types with full metadata (IMDb rating, runtime, trailer, backdrop, poster, certification).
* Multi-Server Streaming Video Player (Iframe Embeds, HTML5 direct video, HLS support, Lights-off dimmer, Theater mode).
* Dynamic TV Show Hierarchy: TV Shows -> Seasons -> Episodes with Next/Prev episode switching.
* Real-Time Instant Live AJAX Search with poster previews and rating tags.
* Advanced Archive Filter Bar (Filter by Type, Genre, Year, Quality, and Sort Order).
* 10-Star Interactive Live Rating System.
* LocalStorage & User Watchlist / Bookmark system.
* Schema.org JSON-LD Structured Data (Movie, TVSeries, TVEpisode) and OpenGraph / Twitter Cards for high SEO ranking.
* Safe Child Theme (doodhtheme-child) included for seamless updates without losing customizations.
* Clean, 100% secure, malware-free codebase.
